# 07. 시연 대본 — 1차 영상(45~60초) · 2차 PT 라이브 데모(5분)

> TL;DR — 장면 순서: 불안(공감) → 안전 게이트 → 워밍업(차가 확인) → 가상 주차(실제 핸들) → **잠금 + 음성 한마디** → **리플레이** → 복기(성취) → 비전 한 줄. 화면 구석 출처 라벨이 항상 보이게.
> **2026-11-08 변경**: 주행 장면이 '아무것도 안 하는 화면'에서 **'화면은 쉬고 목소리가 한마디 하는 장면'**으로 바뀌었다. 영상에서 가장 기억에 남을 7초다 — 반드시 **실제 소리로** 녹음한다.

## 1. 1차 제출용 영상 (45~60초, 가로 녹화 + 자막)
| 시간 | 화면 | 자막/내레이션 |
|---|---|---|
| 0~8초 | 텍스트 카드(또는 숏폼 1~2컷) | “면허는 있는데, 운전석은 여전히 낯설다” |
| 8~15초 | Virtual Console에서 기어 P·주차브레이크 → 앱 게이트 ‘확인’ 3개 | “주차가 확인될 때만 연습이 열립니다” |
| 15~27초 | 벨트 체결 → “딸깍, 좋아요!” / 브레이크 밟고 떼기 → 다음 단계 | “조작하면 차가 확인해 줍니다(에뮬레이터 신호)” |
| 27~37초 | 가상 주차: 핸들 각도 변경 → 화면 바퀴 회전, 칸 안 초록 | “가장 무서운 주차, 차가 멈춰 있을 때 미리” |
| 37~44초 | 기어 D·속도 20 → 잠금 화면(정적) | “달릴 땐 화면이 쉽니다. 도로만 보세요” |
| **44~51초** | **잠금 화면 그대로 두고, 속도를 급히 올림 → 음성만 나온다**: “방금 출발이 조금 급했어요.” | **자막: “화면은 그대로. 필요할 때만 한마디.”** 화면이 1픽셀도 바뀌지 않는 것을 보여 주는 게 핵심 |
| **51~56초** | P 복귀 → **리플레이 타임라인**(0:12 급출발 · 🔊 말했어요 · 30km/h · 한 줄 조언) | “무슨 일이 있었는지, 주차한 뒤에 같이 봅니다” |
| 56~62초 | 복기 카드 · 배지 | “연습 후 3분, 다음 목표 하나” |
| 62~68초 | 로드맵 한 장 | “다음 단계: 제조사와 만드는 진짜 강습모드” |

주의: 실명·계정 노출 금지, 모의 장면은 자막에 ‘모의’, 자체 음원.
**음성 장면 녹음 요령**
- 화면 녹화와 **시스템 오디오를 같이** 잡는다(음성이 영상에 안 들어가면 이 장면의 의미가 사라진다)
- 음악을 함께 재생해 **음악은 줄어들고 안내만 들리는 것**(AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK)을 보여 주면 설득력이 올라간다
- 자막에 **“주행 중 금지는 ‘영상’입니다. 오디오는 오디오 포커스 정책을 지키면 허용됩니다.”** 한 줄을 넣어 심사위원의 첫 의심을 바로 해소한다
- 웹 체험판으로 녹화해도 된다(브라우저 Web Speech API로 실제 소리가 난다). 다만 자막에 **‘웹 체험판 · 모의 신호’**를 표기한다

## 2. 2차 PT 라이브 데모 (약 5분, 에뮬레이터 + Virtual Console 두 창)
1. (30초) 문제: 장롱면허·연수비·가족 연습의 다툼, 주차 공포 — 한 장
2. (60초) 게이트: 콘솔에서 기어 D → “기어를 P에 두면…” → P·주차브레이크 → 활성. **“속도 0이 아니라 P를 봅니다”**
3. (60초) 워밍업: 벨트·브레이크 실신호 완료. 이미 밟은 상태에서 시작해도 완료되지 않음을 보여 줌(T04) → 기술 신뢰
4. (45초) 가상 주차: 콘솔 스티어링 각도 변경 → 바퀴 회전 → 칸 안
5. (30초) 멘토 약속 카드
6. (45초) 주행: 기어 D·속도 → 잠금(정적) → 미션 도중이었으면 재주차 후 새로 시작(T06·T07)
7. **(60초) 주행 중 음성(F12)** — 이 데모의 새 하이라이트
   - 잠금 화면을 띄운 채 콘솔에서 속도를 급히 올린다 → **음성 1회**. 화면은 그대로
   - 바로 다시 급제동 → **말하지 않는다**(45초 간격). “잔소리가 되지 않게 막아 둔 것”을 보여 준다
   - ‘내비 안내 끼어들기’ 버튼 → **그 발화를 버린다**. 내비가 끝나도 뒤늦게 튀어나오지 않는다
   - 멘토 모드로 바꿔 보여 주면: **조수석에 사람이 있으면 기본으로 꺼진다**
8. **(30초) 리플레이(F13)**: 주차 후 타임라인. “3분 12초에 여기서 급제동했네요” — 강사·멘토와 같은 화면을 본다. 점수는 없다
9. (30초) 복기·배지·레벨, ‘혼자 운전 시작’ = 졸업
10. (30초) 3단계 로드맵: 지금(읽기 SDK) → 데이터 기반 연습 → OEM 강습 프로파일(현대차·기아 가속 한도 특허, 쏘카 보조 브레이크 차량 선례)

백업: 에뮬레이터가 죽으면 mock 플레이버(디버그 패널) 녹화본 재생 — 화면에 ‘모의’ 라벨. 그마저 안 되면 웹 체험판(음성 포함)으로 같은 흐름을 보여 준다.
**준비물**: `app-mock-debug.apk`(2026-11-08 빌드 완료), 에뮬레이터 v2.1.0, `adb forward tcp:8088`, 음악 재생용 앱 1개(오디오 포커스 시연), 웹 체험판 탭.

## 3. 예상 질문 짧은 답(상세는 docs/reference 별지 D)
- 차가 안 움직이는데 연습이 되나 → 실력은 사람이 가르치는 주행에서, 앱은 그 앞뒤
- 폰 앱이면 되지 않나 → 확인·맞춤·안전·함께
- 조수석 제동 버튼은 → 공개 SDK에 제어 없음, OEM 과제로 근거와 함께 제안
- **주행 중에 소리를 내도 되나** → 공식 가이드 원문: 금지는 ‘영상’, “오디오 재생은 오디오 포커스 개발 가이드에 정의된 정책을 준수합니다”. 음성 연계는 **권장** 사항(docs/13 §1)
- **그 음성이 주의 분산은 아닌가** → 목표 1개 한정 · 45초 간격 · 주행당 5회 · 한 문장 2.5초 · 지시 대신 사실 · 내비·통화·경고음에 즉시 양보하고 **그 말은 버린다**. 시험 T13 + 단위 테스트 `voice_*`
- **ADAS 경고를 읽는 건가** → 아니다. `READ_ADAS_STATES`는 Signature|Privileged로 서드파티 앱이 못 읽는다(docs/03 §5-1). 속도 변화율·브레이크 페달·방향지시등·핸들 각도·와이퍼·전조등만 쓴다
- MAU → 탑재 차량 10만 대당 300~3,000(가정)
