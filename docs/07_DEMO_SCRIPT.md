# 07. 시연 대본 — 1차 영상(45~60초) · 2차 PT 라이브 데모(5분)

> TL;DR — 장면 순서: 불안(공감) → 안전 게이트 → 워밍업(차가 확인) → 가상 주차(실제 핸들) → 잠금(주행) → 복기(성취) → 비전 한 줄. 화면 구석 출처 라벨이 항상 보이게.

## 1. 1차 제출용 영상 (45~60초, 가로 녹화 + 자막)
| 시간 | 화면 | 자막/내레이션 |
|---|---|---|
| 0~8초 | 텍스트 카드(또는 숏폼 1~2컷) | “면허는 있는데, 운전석은 여전히 낯설다” |
| 8~15초 | Virtual Console에서 기어 P·주차브레이크 → 앱 게이트 ‘확인’ 3개 | “주차가 확인될 때만 연습이 열립니다” |
| 15~27초 | 벨트 체결 → “딸깍, 좋아요!” / 브레이크 밟고 떼기 → 다음 단계 | “조작하면 차가 확인해 줍니다(에뮬레이터 신호)” |
| 27~37초 | 가상 주차: 핸들 각도 변경 → 화면 바퀴 회전, 칸 안 초록 | “가장 무서운 주차, 차가 멈춰 있을 때 미리” |
| 37~45초 | 기어 D·속도 20 → 잠금 화면 | “달릴 땐 화면이 쉽니다. 도로만 보세요” |
| 45~55초 | P 복귀 → 복기 카드 · 배지 | “연습 후 3분, 다음 목표 하나” |
| 55~60초 | 로드맵 한 장 | “다음 단계: 제조사와 만드는 진짜 강습모드” |
주의: 실명·계정 노출 금지, 모의 장면은 자막에 ‘모의’, 자체 음원.

## 2. 2차 PT 라이브 데모 (약 5분, 에뮬레이터 + Virtual Console 두 창)
1. (30초) 문제: 장롱면허·연수비·가족 연습의 다툼, 주차 공포 — 한 장
2. (60초) 게이트: 콘솔에서 기어 D → “기어를 P에 두면…” → P·주차브레이크 → 활성. **“속도 0이 아니라 P를 봅니다”**
3. (60초) 워밍업: 벨트·브레이크 실신호 완료. 이미 밟은 상태에서 시작해도 완료되지 않음을 보여 줌(T04) → 기술 신뢰
4. (45초) 가상 주차: 콘솔 스티어링 각도 변경 → 바퀴 회전 → 칸 안
5. (30초) 멘토 약속 카드
6. (45초) 주행: 기어 D·속도 → 잠금(정적) → 미션 도중이었으면 재주차 후 새로 시작(T06·T07)
7. (30초) 복기·배지·레벨, ‘혼자 운전 시작’ = 졸업
8. (30초) 3단계 로드맵: 지금(읽기 SDK) → 데이터 기반 연습 → OEM 강습 프로파일(현대차·기아 가속 한도 특허, 쏘카 보조 브레이크 차량 선례)
백업: 에뮬레이터가 죽으면 mock 플레이버(디버그 패널) 녹화본 재생 — 화면에 ‘모의’ 라벨.

## 3. 예상 질문 짧은 답(상세는 docs/reference 별지 D)
- 차가 안 움직이는데 연습이 되나 → 실력은 사람이 가르치는 주행에서, 앱은 그 앞뒤
- 폰 앱이면 되지 않나 → 확인·맞춤·안전·함께
- 조수석 제동 버튼은 → 공개 SDK에 제어 없음, OEM 과제로 근거와 함께 제안
- MAU → 탑재 차량 10만 대당 300~3,000(가정)
