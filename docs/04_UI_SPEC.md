# 04. UI 스펙 — 화면 8개 · 문구 · 디자인 토큰

> TL;DR — 가로 화면 기준, 왼쪽은 시스템 Driving view(앱이 가리지 않음). 한 화면 한 행동, 큰 버튼(76dp+), 본문 22sp, 성공은 초록·즉시 칭찬, 출처 라벨 상시. 시안은 `docs/reference/치일까봐_별지A-C_화면시안_구조도_선행사례.pdf` 별지 A.

## 3. 레이아웃 규칙
- 세로 1창(portrait): 위에서 아래로 제목 → 상태 → 행동 1개
- 가로 2창(landscape, 후속): 왼쪽 학습자 미션, 오른쪽 멘토 카드(조수석 쪽)
- 텍스트 입력 없음(칩 선택만)
- CCP 조그 다이얼 포커스 이동 대응(후속): 버튼 순서 = 읽는 순서
