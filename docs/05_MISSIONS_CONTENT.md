# 05. 미션·콘텐츠 — 워밍업, 가상 주차, 약속, 복기, 배지, 칭찬

> TL;DR — 코드의 `core/mission/Missions.kt`, `core/review/Content.kt`, `core/achievement/Achievements.kt`와 1:1. 문구는 짧게, 칭찬은 구체적으로, 실패 대신 ‘한 번 더’. **문구·미션은 Claude Code가 자유롭게 늘리고 다듬어도 된다**(규칙: 실력 판정·운전 기준처럼 읽히는 말 금지).

## 1. 워밍업 미션
| ID | 제목 | 필기 지식 → 내 차에서는 | 판정(시작 이후 변화만) | 힌트 | 칭찬 |
|---|---|---|---|---|---|
| SEAT_BELT | 안전벨트 매기 | 출발 전 전 좌석 안전벨트 → ‘딸깍’ 소리 | 미체결→체결 | 이미 매고 있으면 “한 번 풀었다가 다시 매 볼까요?” | “딸깍, 좋아요! 출발 준비 1단계 완료” |
| BRAKE_PRESS_RELEASE | 브레이크 끝까지 밟고 천천히 떼기 | 브레이크는 오른발, 뒤꿈치를 바닥에 | 밟음→뗌 | “오른발로 브레이크를 끝까지 밟아 주세요” → “이제 천천히 떼 볼까요?” | “끝까지 꾹, 그리고 천천히 떼기 — 좋아요” |
| TURN_SIGNAL | 방향지시등 왼쪽 → 오른쪽 | 진로 변경 30m 전 신호 → 레버 위치 | 왼→오→끔 | “레버 아래로 = 왼쪽” | “깜빡이, 손가락 하나로 충분해요” |
| WIPER(조건부) | 와이퍼 켜고 끄기 | 비 오는 날 시야 | 토글 1회 | “와이퍼 레버를 한 번 움직여 보세요” | “비 오는 날 이 레버, 기억해 둬요” |
| LOW_BEAM(조건부) | 전조등 켜기 | 해 질 녘·터널 | 토글 1회 | “전조등 스위치를 돌려 보세요” | “어두워지면 여기!” |
| STEERING_CENTER(조건부) | 핸들 똑바로 맞추기 | 출발 전 바퀴 정렬 | |각도|≤5° 2초 | “핸들을 가운데로 맞추고 2초 기다려요” | “바퀴가 똑바로! 출발 전에 늘 확인해요” |
| PEDAL_FEEL(조건부) | 살살 밟기 | 급가속 대신 부드럽게 | 20~35% 2초 유지, 표준편차 기록 | “초록 칸 안에서 2초 버텨 보세요” | “방금보다 부드러웠어요” |

추가 후보(자유): 사이드미러 위치 찾기(신호 없으면 ‘찾았어요’ 버튼), 비상등(TurnSignal HAZARD), 기어 단 위치 퀴즈(화면에서만, 실제 기어는 P 유지), 경고등 퀴즈(Safety telltales 조회 가능 시).

## 3. 목표·약속·복기 칩
- 목표: 출발·정지 / 주차 / 차선 바꾸기 / 좌회전 / 그냥 몸풀기
- 멘토 약속(최대 3): 멈출 땐 한 단어로 “멈춰” / 주차 땐 “핸들 반 바퀴”처럼 숫자로 / 잘하면 바로 말해 주기 / 한 번에 하나만 말하기 / 조작하기 전에 먼저 물어보기 / 큰 소리 내지 않기
- 학습자: 자신감 생겼어요 / 후진이 아직 무서워요 / 말이 너무 빨랐어요 / 출발이 어려웠어요 / 생각보다 괜찮았어요
- 멘토: 속도 조절이 좋아졌어 / 핸들 감각이 늘었어 / 주변 확인을 잘했어 / 다음엔 후진 연습하자 / 오늘은 쉬어 가자
- 다음 목표: 후진 주차 속도 / 평행 주차 기준점 / 출발할 때 부드럽게 / 차선 바꾸기 전 확인 / 좌회전 타이밍

## 4-1. 주행 중 음성 대사 사전 (F12 — 2026-11-08 회의 반영)
`web/voice.js`의 `LINES`와 1:1. 각 문구는 **한 문장·2.5초 이내**, 사실 + 짧은 제안. 목표(goal)별로 열리는 항목이 다르다.

| 코드 | 열리는 목표 | 무엇을 보고 | 음성 문구 | 리플레이 한 줄 조언 |
|---|---|---|---|---|
| HARSH_START | 출발·정지 / 몸풀기 | 속도 상승률 급증 | “방금 출발이 조금 급했어요.” | 가속 페달을 2초에 걸쳐 밟아 보세요 |
| HARSH_BRAKE | 출발·정지 / 몸풀기 | 속도 하강률 + 브레이크 페달 | “조금 더 일찍 브레이크를 밟아 볼까요.” | 앞차 브레이크등을 보면 바로 발을 옮기기 |
| NO_SIGNAL | 차선 바꾸기 | 방향지시등 OFF + 핸들 각도 변화 | “차로를 바꿀 땐 깜빡이 먼저요.” | 거울 → 깜빡이 → 어깨 확인 → 이동 |
| LANE_DRIFT | 차선 바꾸기 | 핸들 미세 진동 누적 | “차로 가운데가 조금 흔들렸어요.” | 멀리 보면 손이 덜 움직여요 |
| TAILGATE | 출발·정지 | 전방 거리(가상) | “앞차와 조금 가까워요.” | 2초 간격 = 앞차가 지난 지점을 둘 셀 때 통과 |
| LIGHTS_RAIN | 모든 목표 | 와이퍼 ON + 전조등 OFF | “비가 오네요. 전조등을 켜면 더 잘 보여요.” | 와이퍼를 켤 때 전조등도 같이 |
| TURN_WIDE | 좌회전 | 좌회전 중 핸들 각 부족 | “좌회전은 조금 더 안쪽으로 돌아도 돼요.” | 중앙선 끝을 보고 돌기 |
| PARK_SLOW | 주차 | 후진 중 속도 | “후진은 지금 속도가 좋아요.” | 후진은 걷는 속도보다 느리게 |
| TURN_LEFT_CAUTION | 좌회전 / 몸풀기 | 교차로 접근(가상) 또는 3~35km/h에서 왼쪽 깜빡이 켬 | “좌회전은 마주 오는 차부터 봐요.” | 깜빡이 → 마주 오는 차·횡단보도 확인 → 돌기 |
| TURN_RIGHT_CAUTION | 좌회전 / 몸풀기 | 교차로 접근(가상) 또는 3~35km/h에서 오른쪽 깜빡이 켬 | “우회전 전엔 멈춰서 주위를 봐요.” | 횡단보도 앞에서 한 번 멈추고 보행자 확인 |
| STEADY | 모든 목표 | 달리는 동안 90초간 지적 없음(11/12 회의) | “지금처럼 아주 안정적이에요.” (주행당 1회) | — |

> 11/12 회의: 회전 멘트는 **길 안내가 아니라 주의**만. 방향 안내("~하세요", 거리)는 내비 몫이라 넣지 않는다(테스트 `voice_turn_caution_is_not_navigation`).

**쓰지 않는 문구**: 제한 속도 초과(“속도를 줄이세요”) — 내비와 중복이라 기본 꺼짐. 사고·위험 경고(“위험!”) — 차량 경고 체계가 할 일.

## 5. 칭찬·재시도 문구(11/5 회의 반영)
- 재시도: “조금만 더 천천히 해 볼까요?” / “거의 다 왔어요. 한 번 더” / “괜찮아요, 처음엔 다 그래요”
- 완료: “좋아요” / “해냈어요” / “방금 것, 아주 좋았어요” — 느낌표는 쓰지 않는다(2026-11-10, docs/04 §0-3)
- 금지: “실패”, “틀렸어요”, 점수·등급·순위, “이제 도로에서 혼자 해도 돼요”
