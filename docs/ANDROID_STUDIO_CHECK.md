# Android Studio에서 확인할 것 (2026-11-15)

> 클라우드 환경에서는 컴파일·단위 테스트까지만 확인했다(GitHub CI). **화면이 실제로 맞게 뜨는지, 소리가 나는지는 PC의 Android Studio + Pleos 에뮬레이터에서만 볼 수 있다.** 아래 순서대로 보고, 안 되는 번호와 캡처를 남긴다.
> 준비(저장소 받기·dev로 바꾸기·빌드)는 [SUBMISSION_RUNBOOK.md](SUBMISSION_RUNBOOK.md) 1~2단계.

## 0. 실행 준비
1. 왼쪽 아래 **Build Variants** → `app`을 **mockDebug**로
2. 위쪽 기기 목록에서 **Pleos Connect v2.1.0** 에뮬레이터 → 초록 ▶ Run
3. 앱이 뜨면 오른쪽 아래 노란 **'모의 ▲'** 를 눌러 조작 패널을 연다

## 1. 처음 실행 — 사용법(온보딩)
- [ ] 앱을 처음 켜면 '사용법' 5장이 자동으로 뜬다(1/5 무엇인가요 … 5/5 이 앱 쓰는 법)
- [ ] '다음'으로 끝까지 → '시작하기'를 누르면 닫히고, 앱을 껐다 켜도 다시 뜨지 않는다
- [ ] 안전 확인 화면 메뉴의 **'사용법'** 으로 다시 볼 수 있다

## 2. 안전 확인 화면 메뉴
- [ ] 프로필 줄 아래에 **내 기록 · 설정 · 소개 · 사용법** 칩이 보인다
- [ ] **설정**: 주행 중 음성 켜기/끄기, 3번/5번이 고른 대로 표시되고, 앱을 다시 켜도 유지된다
- [ ] **소개**: 3단계·약속·지금 어디까지가 보이고 '닫기'로 돌아온다
- [ ] **내 기록**: 처음엔 '아직 없어요'. 연습·복기를 한 번 하고 나면 레벨·배지·최근 복기가 늘어난다
- [ ] 메뉴를 연 채로 패널에서 `D`를 누르면(주행) 메뉴가 **바로 닫히고** 잠금 화면이 된다(S04)

## 3. 연습 흐름 (모의 패널로)
1. [ ] `P` → `주차브레이크 true` → 체크 3개가 '확인' → **연습 시작**
2. [ ] 목표 **'출발·정지'** → **혼자 연습**
3. [ ] 워밍업: `벨트`·`브레이크`·`◀`/`▶`를 눌러 진행. 완료 목록이 **"안전벨트 매기 완료"처럼 한글 이름**으로 나온다(전에는 seat_belt 같은 영어가 보였음)
4. [ ] 가상 주차 → 페달(브레이크 27%) → 출발 준비 완료
5. [ ] `D` → **잠금 화면**(화면이 움직이지 않는다)

## 4. 주행 중 음성 (mock 앱만)
- [ ] 잠금 화면에서 **`급가속(모의)`** → 약 2초 뒤 **"속도가 빠르게 늘었어요."**가 들린다
- [ ] 바로 한 번 더 눌러도 말하지 않는다(45초 간격 규칙)
- [ ] 설정에서 음성을 **끄고** 다시 주행하면 말하지 않는다
- 안 들리면: 에뮬레이터 볼륨(옆 툴바 🔊), 에뮬레이터 설정 → 시스템 → 언어 → 음성 출력(TTS)에 한국어가 있는지, Logcat에서 `TextToSpeech` 검색

## 5. 복기
- [ ] `P` + `주차브레이크` → 복기 화면 제목이 **"수고했어요"**(느낌표 없음)
- [ ] 속도 시간표에 점이 찍히고, 아래 목록 중 말한 사건 끝에 **"주행 중에 말했어요(모의)"**
- [ ] 저장 → 배지 알림이 2초 뜨고 사라진다 → 내 기록에 복기가 생긴다

## 6. 성능 (Android Studio 아래 **Profiler**)
- [ ] 정차 화면 30초, 잠금 화면 30초 동안 **CPU %**와 **Memory(MB)**를 적는다. 팀 목표는 CPU 3% 이하, 메모리 400MB 이하(Pleos 권장)
- [ ] 적은 값은 [VERIFICATION_LOG.md](VERIFICATION_LOG.md)에

## 7. 차량 신호용(vehicle) — 선택
- Build Variants를 **vehicleDebug**로 바꾸고 실행. Virtual Console(`adb forward tcp:8088 tcp:8088` → 브라우저 `http://127.0.0.1:8088/`)을 만져 본다
- 예상: 주차 브레이크 ON을 콘솔로 만들 수 없어 **안전 확인에서 잠긴다**(A01 실측). 설정 화면에는 "차량 신호용 앱은 주행 중에 말하지 않아요"가 보인다
