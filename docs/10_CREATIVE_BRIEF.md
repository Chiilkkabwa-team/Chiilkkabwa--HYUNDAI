# 10. 크리에이티브 브리프 — Claude Code가 자유롭게 키워 갈 영역

> TL;DR — CLAUDE.md의 '반드시 지킬 규칙'(안전·정직·블라인드) 10개만 지키면 나머지는 열려 있다. 스캐폴드는 출발점일 뿐이니 화면·문구·구조·연출은 더 좋게 바꿔도 된다. 아래는 방향과 아이디어 창고이지 명령이 아니다.

## 1. 한 장 기획안
**이름**: 치일까봐 — “길을 건널 때는 치일까 봐, 운전석에선 칠까 봐.” 누구나 처음엔 겁나는 그 마음.
**누구**: 면허는 있지만 운전이 두려운 초보·장롱면허 운전자 + 옆자리에서 가르치는 가족·지인
**언제**: 가족 차로 연습하기 직전과 직후, 차가 멈춰 있는 시간
**무엇**: 연습 전 5분(차가 조작을 확인) → 주행 중 0터치(화면이 쉰다) → 연습 후 3분(돌아보고 다음 목표)
**왜 차에서**: 폰은 ‘했다고 믿을’ 뿐, 차는 ‘했는지 안다’ / 내 차 크기·사양 / 움직이면 스스로 잠김 / 둘이 같은 화면
**감정 목표**: ‘평가받는다’가 아니라 **‘해냈다’**. 초보 표지 붙이고 위축됐던 기억을 뒤집는 작은 성취의 연속
**톤**: 다정하지만 수다스럽지 않음. 한 화면 한 문장. 실패라는 말 없음
**성공 장면(심사위원이 기억할 것)**: Virtual Console에서 벨트를 채우는 순간 차량 화면에 “딸깍, 좋아요!” / 콘솔 핸들 각도에 따라 화면 속 내 차 바퀴가 꺾이는 가상 주차 / 기어 D에서 조용히 잠기는 화면

## 2. 자유롭게 해도 되는 것 (권장)
- 화면 구성·애니메이션(정차 중, 2초 이내)·일러스트·아이콘 — 독자 디자인이면 무엇이든
- 오리지널 캐릭터(예: 이전 기획의 조수석 친구 ‘콩발’ 같은 독자 캐릭터). 기존 캐릭터(치이카와 등)·현대 로고는 금지
- 미션 추가·순서 변경·난이도 단계(‘3번째 연습부터 평행 주차 열림’ 등)
- 가상 주차 물리·그래픽 고도화(궤적 미리보기 점선, 기준점 하이라이트, 사각지대 표시)
- 성취 연출: 레벨 이름(예: 1 첫 시동 → 5 혼자 출발), 수료 카드 디자인, 연습 달력
- 멘토 UX: 가로 2창에서 조수석 쪽 멘토 카드, ‘오늘의 한 마디’ 카드
- 접근성: 큰 글씨 모드, 다국어(영어) 문구 파일
- 코드 구조 개선(Hilt, DataStore, Navigation 등) — core의 테스트를 깨지 않는 한

## 3. 아이디어 창고 (고르면 docs/09에 추가)
| 아이디어 | 왜 좋은가 | 주의 |
|---|---|---|
| ★ 지난 연습과 비교하는 ‘성장 곡선’(페달 표준편차, 미션 첫 시도 성공) | 숫자 좋아하는 심사위원(11/5 회의) + 뿌듯함 | ‘실력 점수’가 아니라 ‘내 기록 비교’로 표현 |
| ★ 멘토 먼저 해 보기 | “살살이 얼마큼인지” 같은 화면 기준 → 다툼 감소 스토리 | 멘토 결과도 본인만 봄 |
| 주차장 미니 코스 카드(‘오늘은 3번 기둥까지 직진 후 후진’) | 혼자 연습도 구조화 | 실제 지시처럼 들리지 않게 ‘예시 코스’ |
| 필기→실전 퀴즈(표지판 보고 버튼 찾기) | 노션 팀 메모 ‘필기 지식을 실전에’ | 정차 중만 |
| 연습 달력·연속 기록 | 재이용(30일 재개율) | 압박 문구 금지 |
| ★ 강습모드 차량 프로파일 콘셉트 화면(로드맵 3단계) | 팀이 원한 출력 제한·조수석 정지 요청 비전을 ‘보여 주기’ | 반드시 ‘제조사 협업 가정 · 가상’ 라벨, 실제 제어 API 호출·가짜 패킷 금지, 앱 안 시뮬레이터에서만 |

| 음성 칭찬(정차 중) | 생동감 | 오디오 포커스, 주행 중 금지 |
