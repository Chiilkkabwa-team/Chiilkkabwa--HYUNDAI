## 2. "왜 주행 중에 소개·사용법이 안 열렸나" — 근거와 판단

- **안 열린 이유(코드)**: 오버레이 창을 그리는 함수가 `DRIVING_LOCK` 단계에서는 모든 창을 막고 있었다. 소개·사용법도 같은 창 장치를 써서 함께 막혔다.
- **멈춰도 안 열린 이유(규칙)**: 앱은 **기어 P + 주차 브레이크 + 주행 제한 없음**이 모두 확인될 때만 '주차'로 본다(S03). 신호 대기처럼 D에서 속도 0으로 멈춘 건 주차가 아니라서 주행 단계가 그대로다. 이건 의도된 안전 규칙이라 **완화하지 않는다**.
- **판단**: 소개·사용법은 차 화면 안의 앱이 아니라 **웹 체험판을 설명하는 창**(머리말, 차 화면 밖)이다. 그래서 주행 중에도 열게 바꿨다. 대신
  - 창 맨 위에 "웹 체험판 안내예요. 열려 있는 동안 가상 주행은 멈춰 있어요. 실제 차에서는 주행 중에 이런 창이 뜨지 않아요"를 띄우고
  - 창이 열려 있는 동안 가상 주행 시간을 멈춘다(읽는 사이 가상 차가 계속 달리지 않게)
- **'내 기록'·'나'(앱 안의 창)는 그대로 주행 중 잠금**(S04). 흐리게 표시하고 이유를 버튼 설명에 적었다. 전에는 주행 중 누르면 반응이 없다가 **주차하는 순간 갑자기 떴는데**(누른 기록이 남아서), 이것도 고쳤다.
- 주행 잠금 화면에 "멈췄는데도 안 열리나요? 신호 대기처럼 잠깐 멈춘 건 주차가 아니에요. 기어 P에 두고 주차 브레이크를 걸면 열려요" 한 줄을 넣었다. 주행에 들어갈 때 한 번 정해지고 바뀌지 않는 정적 문구다(S04).

## 3. 하단 바(GNB) 안내 문구

| 누른 곳 | 말풍선 |
|---|---|
| 내비·미디어·전화·앱 라이브러리·홈 | "○○는 실제 차에서 열리는 앱이에요. 이 데모에서는 치일까봐만 열려요" |
| 공조 온도·서리 제거·시트 열선·차량 설정 | "○○는 차가 직접 다루는 기능이라 데모에서는 바꿀 수 없어요. 치일까봐는 차를 조작하지 않아요" |
| 치일까봐 | "지금 보고 있는 치일까봐예요" |

- 말풍선은 앱 화면이 아니라 하단 바 바로 위(시스템 영역)에 뜨고 2.6초 뒤 사라진다. 주행 중에는 움직임 없이 나타난다.
- 받침에 맞게 '은/는'을 고른다("내비는", "홈은").
- 키보드(Enter·Space)로도 누를 수 있다.

## 4. 원 채팅 요약(맥락)

- 분업: A 차량·시뮬레이터, B 음성·운전 학습, **C 복기·기록·UI = 김태환**. B 담당은 A·C를 돕기로.
- 우선순위는 v3 분업안의 P0 → P1 → P2. 3D(A06)는 P2.
- 앱으로 옮길 때: 웹의 판단 로직은 거의 그대로 옮기고 화면만 앱 방식으로 다시 그린다.
- Vercel은 새 팀 레포에서 받아 배포되는 것을 확인. `main`에 병합할 때마다 자동 갱신되는지는 다음 병합에서 확인.
