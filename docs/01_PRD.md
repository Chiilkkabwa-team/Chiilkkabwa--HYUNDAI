# 01. PRD — 치일까봐 MVP+ 제품 요구사항

> TL;DR — 정차 중: 안전 게이트 → 목표 → 워밍업(차량 신호 확인) → 가상 주차 → (페달) → 멘토 약속. 주행 중: 정적 잠금. 재주차: 트립 기반 복기 → 배지 → 다음 목표. 모든 판정은 읽기 전용 신호로.

## 1. 사용자
| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 학습자(초보·장롱면허) | 가족 차로 연습 직전·직후, 주차장 | 조작을 몸으로 익히고 ‘해냈다’는 감각, 연습이 이어지는 느낌 |
| 멘토(가족·지인) | 조수석 | 무엇을 어떤 말로 가르칠지 미리 맞추기, 다툼 줄이기 |
| 경력자(후속) | 가르치기 전 | 내 페달·핸들 감각 점검 |

## 2. 기능과 인수 기준 (MVP = M5까지)
### F1 안전 게이트 (필수)
- 기어 P + 주차 브레이크 ON + CarUxRestrictions 비제한이 모두 OK일 때만 ‘연습 시작’ 활성
- 하나라도 UNKNOWN/DISCONNECTED → 잠금, 한 문장 이유 표시
- 인수: T01, T02 / 단위 테스트 gate_*

### F2 목표 고르기 (필수)
- 5개 중 1개(출발·정지/주차/차선 바꾸기/좌회전/그냥 몸풀기), 혼자/멘토 선택
- 조수석 착석 신호가 있으면 ‘멘토와 함께’ 강조
- 지난 목표가 있으면 첫 화면에 “지난번 목표: … 이어서 해 볼까요?”

### F3 운전석 워밍업 (필수 3 + 조건부 3)
- 필수: 안전벨트(미체결→체결), 브레이크(밟음→뗌), 방향지시등(좌→우→끔)
- 조건부: 와이퍼 토글, 전조등 토글, 핸들 정렬(|각도|≤5°, 2초)
- 성공 즉시(0.25초 내) 구체적 칭찬, 실패는 없음(힌트만)
- 신호 미지원/권한 거부/끊김 → 원인별 문구 + ‘건너뛰기’
- 인수: T03~T05, 단위 테스트 brake_*, belt_*, turn_*

### F4 내 차로 하는 가상 주차 (필수: 화면 / 조건부: 핸들 연동)
- 차체 치수(CarInfo, 없으면 기본값 + ‘기본값’ 표시)로 탑뷰
- 핸들 각도 신호가 있으면 실제 핸들로 조향, 없으면 화면 슬라이더
- 전진/후진 버튼, 칸 안 판정(위치 ±0.35m, 방향 ±6°)
- 정차 중 전용, 출처 라벨 ‘모의’(화면 속 연습이므로)
- 인수: 단위 테스트 parking_*, 시연에서 핸들 돌리면 바퀴가 따라 움직임

### F5 페달 감각 ‘살살 밟기’ (조건부)
- AAOS ACCELERATOR_PEDAL_COMPRESSION_PERCENTAGE OK일 때만, 20~35% 2초 유지
- 미지원·권한 거부면 자동 생략
- **가속 페달은 차가 구동되지 않는 조건 확인 전까지 실차에서 열지 않는다**(에뮬레이터·EV OFF 확인 후 팀 결정). 대안: 브레이크 페달 압력으로 같은 미션
- 2026-11-05: 웹·앱 모두 **기본을 브레이크 페달 압력**으로 바꿈(가속 페달 미션은 위 조건 확인 후에만)

### F6 멘토 약속 카드 (멘토 모드 필수)
- 6개 중 최대 3개 선택 → ‘둘 다 약속했어요’

### F7 주행 중 잠금 (필수)
- 게이트가 DRIVING_RESTRICTED 또는 NOT_IN_PARK(준비 이후) → 정적 잠금 화면
- 진입 시 트립값 저장, 미션 일시정지, 소리·애니메이션 없음
- 인수: T06, T12

### F8 주차 후 복기 (필수)
- 재주차(게이트 Ready) → 트립 차이(거리·시간), 없으면 앱 시계(‘앱 기준 시간’ 표시)
- 학습자 칩 1, 멘토 칩 1(멘토 모드), 다음 목표 1 → 저장
- ‘혼자 운전 시작할래요’ → 졸업 처리(GRADUATE 배지, 수료 카드는 후속)
- 인수: 단위 테스트 session_*, summary_*

### F9 배지·레벨 (필수, 정차 중만)
- 9종 배지(docs/05), 2초 토스트, 모의로 얻은 배지는 ‘(모의)’
- 레벨 1~5 = 복기 횟수 기반(실력 아님)

### F10 프로필 (필수)
- 기기 내 프로필(별칭), 삭제 가능, 다른 프로필 기록 비노출(T10)

### F11 디버그 패널 (mock 전용)
- 모든 신호 조작 + 예외 재현(미지원)

## 3. 후속(MVP 이후)
| 기능 | 조건 |
|---|---|
| 정차 중 음성 칭찬(TTS) | Pleos TTS 상태 확인, 없으면 Android TextToSpeech, 오디오 포커스 |
| 수료 카드 내보내기(이미지) | 사용자 직접 공유만 |
| 내 운전 점검(경력자) | 페달·핸들 정차 테스트 |
| 주행 습관 리포트 | 주행 중 저빈도 기록 허용 여부 운영진 확인 후 |
| Gleo AI 음성 진입 | App Schema 연동 신청 |
| 가로 2창 멘토 카드 | landscape 2-window 대응 |

## 4. 하지 않는 것
차량 제어(제동·출력·ADAS 설정), 주행 중 코칭·경고, 운전 실력 점수·랭킹 공개, 사고 대응 안내(SOS), 서버·계정·위치·VIN, LLM.
