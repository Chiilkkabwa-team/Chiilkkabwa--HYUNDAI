# 01. PRD — 치일까봐 MVP+ 제품 요구사항

> TL;DR — 주차 중: 안전 게이트 → 목표 → 워밍업(차량 신호 확인) → 가상 주차 → (페달) → 멘토 약속. 주행 중: 화면은 정적 잠금, **음성 길잡이만**(F12). 재주차: 트립 기반 복기 + 리플레이(F13) → 배지 → 다음 목표. 모든 판정은 읽기 전용 신호로.

## 1. 사용자

**핵심 사용자 = 면허는 있지만 운전이 두려운 사람.** 혼자 연습하든 누구와 함께하든 성립한다. '가족과 함께'는 가장 흔한 장면이지 조건이 아니다(2026-11-08 회의 반영, docs/13 §6).

| 사용자 | 상황 | 원하는 것 | 이 앱이 옆자리 역할을 하는 방법 |
|---|---|---|---|
| 학습자 — **혼자 연습** | 집 앞 주차장, 한가한 시간대 | 물어볼 사람이 없다. 뭘 잘못했는지 모른 채 끝난다 | 출발 전 화면 + **주행 중 음성 길잡이(F12)** + 주차 후 리플레이(F13) |
| 학습자 — **함께 연습** | 가족·지인 차로 연습 직전·직후 | 조작을 몸으로 익히고 ‘해냈다’는 감각, 다툼 없는 연습 | 출발 전 화면 + **멘토 약속 카드(F6)** (음성은 기본 꺼짐) |
| 멘토(가족·지인) | 조수석 | 무엇을 어떤 말로 가르칠지 미리 맞추기 | 약속 카드 + 주차 후 같은 화면 보며 복기 |
| 강사·방문 연수(후속) | 수업 전후 | 지난주에 혼자 무엇을 연습했는지 | 리플레이(F13) 타임라인을 수강생이 보여 준다 |
| 경력자(후속) | 가르치기 전 | 내 페달·핸들 감각 점검 | 정차 중 페달·핸들 테스트 |

> **두 모드는 동등하다.** 혼자 연습 = 음성 길잡이 기본 켜짐 / 함께 연습 = 음성 기본 꺼짐, 멘토 약속 카드가 그 역할. 어느 쪽도 '축소판'이 아니다.

## 2. 기능과 인수 기준 (MVP = M5까지)
### F1 안전 게이트 (필수)
- 기어 P + 주차 브레이크 ON + CarUxRestrictions 비제한이 모두 OK일 때만 ‘연습 시작’ 활성
- 하나라도 UNKNOWN/DISCONNECTED → 잠금, 한 문장 이유 표시
- 인수: T01, T02 / 단위 테스트 gate_*

### F2 목표 고르기 (필수)
- 5개 중 1개(출발·정지/주차/차선 바꾸기/좌회전/그냥 몸풀기), 혼자/멘토 선택
- 조수석 착석 신호가 있으면 ‘멘토와 함께’ 강조
- 지난 목표가 있으면 첫 화면에 “지난번 목표: … 이어서 해 볼까요?”

### F3 운전석 워밍업 (필수 3 + 조건부 3)
- 필수: 안전벨트(미체결→체결), 브레이크(밟음→뗌), 방향지시등(좌→우→끔)
- 조건부: 와이퍼 토글, 전조등 토글, 핸들 정렬(|각도|≤5°, 2초)
- 성공 즉시(0.25초 내) 구체적 칭찬, 실패는 없음(힌트만)
- 신호 미지원/권한 거부/끊김 → 원인별 문구 + ‘건너뛰기’
- 인수: T03~T05, 단위 테스트 brake_*, belt_*, turn_*

### F4 내 차로 하는 가상 주차 (필수: 화면 / 조건부: 핸들 연동)
- 차체 치수(CarInfo, 없으면 기본값 + ‘기본값’ 표시)로 탑뷰
- 핸들 각도 신호가 있으면 실제 핸들로 조향, 없으면 화면 슬라이더
- 전진/후진 버튼, 칸 안 판정(위치 ±0.35m, 방향 ±6°)
- 정차 중 전용, 출처 라벨 ‘모의’(화면 속 연습이므로)
- 인수: 단위 테스트 parking_*, 시연에서 핸들 돌리면 바퀴가 따라 움직임

### F5 페달 감각 ‘살살 밟기’ (조건부)
- AAOS ACCELERATOR_PEDAL_COMPRESSION_PERCENTAGE OK일 때만, 20~35% 2초 유지
- 미지원·권한 거부면 자동 생략
- **가속 페달은 차가 구동되지 않는 조건 확인 전까지 실차에서 열지 않는다**(에뮬레이터·EV OFF 확인 후 팀 결정). 대안: 브레이크 페달 압력으로 같은 미션
- 2026-11-05: 웹·앱 모두 **기본을 브레이크 페달 압력**으로 바꿈(가속 페달 미션은 위 조건 확인 후에만)

### F6 멘토 약속 카드 (멘토 모드 필수)
- 6개 중 최대 3개 선택 → ‘둘 다 약속했어요’

### F7 주행 중 화면 잠금 (필수)
- 게이트가 DRIVING_RESTRICTED 또는 NOT_IN_PARK(준비 이후) → 정적 잠금 화면
- 진입 시 트립값 저장, 미션 일시정지, **영상·애니메이션·화면 전환·터치 입력 없음**
- **소리는 F12 음성 길잡이만** 허용(오디오 포커스 정책 준수). 토스트·효과음·배지 알림은 주행 중 금지
- 인수: T06, T12

### F8 주차 후 복기 (필수)
- 재주차(게이트 Ready) → 트립 차이(거리·시간), 없으면 앱 시계(‘앱 기준 시간’ 표시)
- 학습자 칩 1, 멘토 칩 1(멘토 모드), 다음 목표 1 → 저장
- ‘혼자 운전 시작할래요’ → 졸업 처리(GRADUATE 배지, 수료 카드는 후속)
- 인수: 단위 테스트 session_*, summary_*

### F9 배지·레벨 (필수, 정차 중만)
- 9종 배지(docs/05), 2초 토스트, 모의로 얻은 배지는 ‘(모의)’
- 레벨 1~5 = 복기 횟수 기반(실력 아님)

### F10 프로필 (필수)
- 기기 내 프로필(별칭), 삭제 가능, 다른 프로필 기록 비노출(T10)

### F11 디버그 패널 (mock 전용)
- 모든 신호 조작 + 예외 재현(미지원)

### F12 주행 중 음성 길잡이 ‘조용한 동승자’ (필수 — 혼자 연습 모드)
공식 가이드상 주행 중 금지는 **영상**이고, 오디오는 **오디오 포커스 정책을 지키면 허용**된다(근거 원문 docs/13 §1). 음성 연계 인터랙션은 오히려 권장 사항이다.

- **화면은 잠긴 그대로.** 음성이 나와도 화면은 바뀌지 않는다(DO 미선언 유지)
- **출발 전에 고른 목표 1개에 대해서만** 반응. 나머지 상황은 침묵
- **빈도 상한**: 최소 간격 45초, 1회 주행당 **최대 5회**(초과 시 말하지 않음)
- **길이**: 한 문장, 2.5초 이내. **지시가 아니라 사실 + 짧은 제안**("핸들 더 꺾으세요" ❌ → "방금 출발이 조금 급했어요" ⭕)
- **양보**: 내비 안내·통화·차량 경고음 → 즉시 중단, 그 발화는 **버린다**(나중에 다시 말하지 않음)
- **멘토 동승 시 기본 꺼짐**, 혼자 연습이면 기본 켜짐. 설정 토글로 언제든 끌 수 있고 끈 상태가 저장된다
- 제한 속도 초과는 **기본으로 말하지 않는다**(내비와 중복 + 잔소리)
- 판정 입력(공개 SDK 범위): 속도 변화율(급출발·급제동), 브레이크 페달, 방향지시등 + 핸들 각도(무신호 차로 변경), 와이퍼 ON + 전조등 OFF
- 구현: Pleos `TextToSpeech` ON_DEVICE(앱 등록 불필요) → 미지원 시 Android `TextToSpeech`. `AudioFocusRequest`는 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`
- 인수: **T13**(빈도·길이·양보), 단위 테스트 `voice_*`

### F13 주행 리플레이 (필수 — 복기 화면 안)
주차 후, 오늘 주행에서 기록된 순간을 **시간순 타임라인**으로 보여 준다. 점수·등급은 없다.

- 각 항목: `경과 시각 · 무슨 일이 있었는지 · 그때 속도 · 한 줄 조언 · 어떤 신호로 알았는지(출처 라벨)`
- 아무 일도 없었으면 "오늘은 특별히 기록된 순간이 없어요. 안정적으로 다녀왔네요."
- 멘토·강사와 **같은 화면을 보며** 복기할 수 있다("3분 12초에 여기서 급제동했네요")
- 음성으로 말한 항목은 🔊 표시(말한 것과 기록이 일치해야 한다)
- **기기 안에만 저장**, 내보내기는 사용자가 직접 할 때만. 서버·업로드 없음
- 인수: **T14**, 단위 테스트 `replay_*`

## 3. 후속(MVP 이후)
| 기능 | 조건 |
|---|---|
| 주차 중 음성 칭찬(TTS) | 주행 중(F12)과 같은 오디오 포커스 경로 재사용 |
| 좌석 구역 지정 음성 | TTS `setAudioZoneId`로 운전석 구역만 재생 가능 여부 Day1 확인 |
| 수료 카드 내보내기(이미지) | 사용자 직접 공유만 |
| 내 운전 점검(경력자) | 페달·핸들 정차 테스트 |
| 리플레이 강사 공유(PDF·이미지) | 사용자가 직접 내보낼 때만, 서버 경유 없음 |
| Gleo AI 음성 진입 | App Schema 연동 신청 |
| 가로 2창 멘토 카드 | landscape 2-window 대응 |

## 4. 하지 않는 것
차량 제어(제동·출력·ADAS 설정), **주행 중 화면 표시·터치 입력**, **주행 중 지시형 명령**(‘핸들 꺾으세요’처럼 조작을 지시하는 말), 운전 실력 점수·등급·랭킹 공개, 사고 대응 안내(SOS), 서버·계정·위치·VIN, LLM.

> 음성 길잡이는 **점수가 아니라 그 순간의 사실**만 말한다. 앱은 운전 실력을 판정하지 않는다.
