## 범위와 기존 코드 분석

대상은 `web/sim.js`, 콘솔·시연 연결 `web/app.js`/`index.html`, 복기 필드 보존 `web/voice.js`와 웹 테스트다. Android A01 신호, A02 Kotlin 이벤트 엔진, Manifest/Gradle 및 음성 우선순위·간격·횟수 정책은 변경하지 않았다.

- `junctionAt(k)`의 기존 배치(300m부터 280m 간격, 우/좌 교대)와 `nextJunction(s)`의 교차로 출구 경계까지 현재 교차로를 반환하는 규칙을 재사용했다. 교차로 폭은 12m다.
- 기존 `stepJunction()`은 구간 방향과 깜빡이가 같으면 회전, 다르면 직진으로 처리해 반대 신호와 가상 진행을 구분하지 못했다. 1.5m/s 이하 접근 알림 누락, 프레임이 교차로 전체를 건너뛸 때 진입 누락, 여러 오류 중 마지막 이벤트에만 방향 부착도 보완 대상이었다.
- 도로는 계속 곧게 이어지는 **2D Mock**이다. 실제 회전 궤적·보행자·차선 위험을 감지하거나 3D 차량 물리를 구현한 것이 아니다. 화면의 회전 곡선은 판정 피드백이다.

## 판정 규칙

1. 콘솔의 `maneuver=STRAIGHT/LEFT/RIGHT`와 `signal=NONE/LEFT/RIGHT`는 독립 입력이다. 기본 진행은 직진이며 교차로 진입 후 콘솔 선택은 직진으로 복원된다. 깜빡이·핸들 각도만으로 회전했다고 추론하지 않는다.
2. 차량 앞끝과 진입 경계의 거리가 0m 초과~60m 이내면 교차로별 접근 이벤트를 한 번 남긴다. 정지·저속도 접근은 알릴 수 있지만 회전/통과 성공은 아니다.
3. 앞끝이 경계를 **앞으로 통과할 때만** 진입을 판정한다. 한 프레임 전후의 가상 위치·속도·가로 위치·시각으로 진입점을 선형 보간한다. 실제 센서 측정값이 아니다. 동일 교차로는 신호 변경·대기·위치 되돌림에도 다시 채점하지 않는다.
4. 좌/우회전은 구간 방향 일치, 깜빡이 일치, 맨 왼쪽/오른쪽 가상 차로에 차체 전체 포함, 진입 속도 25km/h 이하를 각각 확인한다. 하나라도 불일치면 성공 이벤트를 만들지 않고 모든 해당 오류를 기록한다. 25km/h 초과는 반올림 전 수치로 판단한다.
5. 직진은 회전 감점 없이 별도 통과 기록을 남긴다. 직진에 깜빡이가 켜져 있으면 신호 불일치도 기록한다. 알 수 없는 진행은 판정 보류, 비정상 위치/속도 값은 채점하지 않는다.

차로와 25km/h는 이 웹 Mock의 연습 규칙이다. 실제 도로에서의 통행 허용·법규·안전 속도 판단 기준이 아니다.

## B/C 파트 이벤트 계약

기존 이벤트 코드와 기본 의미·점수·분류를 유지했다.

| 코드 | 시점 / 의미 |
|---|---|
| `JUNCTION_AHEAD` | 접근 / `dir`은 가상 회전 구간 방향. 기존 `TURN_LEFT_CAUTION`/`TURN_RIGHT_CAUTION` 연결 유지 |
| `TURN_GOOD` | 진입 / 네 회전 조건이 모두 충족됨 |
| `TURN_FAST` | 진입 / 가상 회전 속도 기준 초과 |
| `TURN_WRONG_LANE` | 진입 / 회전 차로 또는 차체 전체 포함 조건 불충족 |
| `TURN_WRONG_SIGNAL` (추가) | 진입 / 가상 진행과 깜빡이 불일치·미표시·불명 |
| `TURN_WRONG_DIRECTION` (추가) | 진입 / 선택한 가상 회전과 연습 구간 방향 불일치 |
| `JUNCTION_STRAIGHT` (추가) | 진입 / 가상 직진 통과, 정보 기록 |
| `JUNCTION_UNAVAILABLE` (추가) | 진입 / 가상 진행 불명, 판정 보류 |

공통 추가 필드: `junctionK`, `dir`, `segmentDir`, `phase=APPROACH/ENTRY`, `source=MOCK`, `basis`. 기존 `t`는 주행 시작 이후 시뮬레이션 경과 초이며 실제 일시나 차량 센서 시각이 아니다. `dir`은 접근에서 구간 방향, 진입에서 사용자가 선택한 가상 진행이다.

진입 `basis`는 `model=2D_MOCK`, `sampling=LINEAR_ENTRY`, 깜빡이, 가상 차로, 가로 위치(m), 속도(km/h), 회전 속도 기준, 필요한 차로 및 각 조건의 true/false를 보존한다. 접근 근거는 `distanceM`이다. 오류가 겹쳐도 모든 기록에 같은 방향·시각·근거가 붙는다. 보고서와 JSON 복기 저장 후에도 근거를 유지하며, 명시된 Mock 출처를 상위 인자로 실차 출처로 바꾸지 않는다. 새 오류 코드에 대한 음성 대사를 임의 추가하지 않았다.
